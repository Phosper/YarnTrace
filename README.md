# YarnTrace · 剥图消消

一张像素画被拆成很多条毛线，每条毛线的头上有一个箭头。点一下，它就顺着箭头、沿着自己的身体一节一节溜出棋盘：

- **能出去** → 整条滑走，原来的位置留下一圈淡淡的底图。
- **被挡住** → 滑到挡路的那条跟前撞一下，对方闪红，然后原路缩回（棋盘状态完全不变）。

把整张图拆干净就过关，拆完后原图会一格一格弹回来。**没有倒计时，也不会失败**；少碰壁能多拿星星。

## 快速开始

```bash
npm install
npm run dev      # 手机同局域网可直接访问，Vite 已开 host
npm run build    # 类型检查 + 产物到 dist/
npm test         # 规则 / 求解 / 生成器 / 会话 / 图案库 / 图片管线
npm run icons    # 重新生成 public/ 下的应用图标
```

产物是纯静态文件（约 55 KB JS + 9 KB CSS，gzip 后约 26 KB），资源路径全部是相对路径，扔到 GitHub Pages、Vercel、Cloudflare Pages 或任意静态主机的任意子目录都能跑，不需要后端。

## 关卡从哪来

一道关卡 = 像素图 + 切分，图最后都归一成 `Art { w, h, palette, color }`。

| 来源 | 说明 |
| --- | --- |
| 图案库（40 关主线） | `src/art/pictures.ts`：爱心、苹果、小猫、熊猫、火箭、城堡……每关一张，第 1 关 12 格，逐步长到第 40 关 32 格 |
| 随机一局 | 种子决定用哪张图、多大、怎么切；URL `?s=<seed>` 可复现同一局 |
| 我的图片 | 选关面板「用我的图片」，本地解析，不上传服务器 |

`?l=<n>` 可以直接打开第 n 关。

### 图案怎么画出来的

图案不是手敲的像素表，而是 100×100 坐标里的一组矢量形状（椭圆、圆角矩形、多边形、粗折线，外加「擦除」和「裁剪」），由 `src/art/raster.ts` 按需要的格数光栅化：

1. 每格取 4×4 个采样点，覆盖率够了才算有格子，颜色取票数最多的那层；
2. 轮廓上的格子换成同色系的深色描边，20 格以上的图再加一圈高光/暗部；
3. 裁掉四周空行空列。

所以同一张图既能当 12 格的热身关，也能当 32 格的后期关，加一张新图只要往 `PICTURES` 里添一条。

### 怎么保证一定能通关

切分用「剥皮法」（`src/game/generator.ts`）：每次只从**此刻就能滑出去**的格子上起一条新毛线，把它从剩余格子里摘掉，再继续。施工顺序本身就是一条合法通关路线，关卡天然 100% 可解，不需要「生成完再校验」。

> 为什么永远不会卡死：只要还有剩余格子，取其中最靠上的一格，它 ↑ 方向的格子 y 都更小，必然不在剩余集合里，所以它一定能出去。

毛线生长时不会长到自己头的正前方，所以判定只看**头部射线**，而画面上身体正好沿着头走过的路跟出去，两者一致。

## 目录

```
src/
  game/      types / rng / rules / solver / generator / registry / session / score
  art/       矢量形状光栅化、图案库、上传图片的量化管线
  render/    相机、毛线画法、贴图缓存、棋盘绘制、粒子

tests/       规则、求解、生成器、会话、图案库、图片管线
```

## 手感相关的实现

- **点击不排队**：毛线一被点中就从棋盘状态里移除，只有画面还在滑，所以可以一路连点；连续送走会累计连击，音调沿五声音阶一路升高，碰壁则清零。
- **毛线画法**：静止的毛线按「颜色 × 连接方向 × 是否是头」缓存成贴图，贴图只在几个固定尺寸上栅格化，缩放时不用每帧重画；滑动中的毛线用同一套笔画参数实时描，起步瞬间和贴图完全重合。
- **底图**：整张图以 1 像素 1 格画在离屏画布上，放大不插值，作为毛线下面的衬底；通关时同一张图逐格弹回。
- **星级**：`src/game/score.ts`，只看碰壁次数占毛线总数的比例，门槛故意放得宽。

## 操作

- 点毛线上任意一格 = 点这条毛线
- 双指捏合 / 滚轮 = 缩放，拖动 = 平移
- 底部「提示」高亮一条现在能走的毛线（键盘 `H`）
- 底部左右两个按钮：重来（`R`）、复位视角（`F`）

## 离线与安装

正式构建会注册 `public/sw.js`：页面本身走「网络优先」，新版本下次打开就生效；带哈希的资源走「缓存优先」。第一次访问结束后即可离线游玩，也可以「添加到主屏幕」当独立应用用。开发模式（`npm run dev`）不注册 service worker。

## 已知取舍

- 图案颜色按像素保留，所以同一条毛线可能有多种颜色 —— 图案能和原图 1:1 对上。
- 碰撞只做头部射线判定；`Session` 的 `mode` 仍可切到 `swept` 做整条扫掠，但画面的滑出动画是按头部射线语义做的。
- 分享优先调用系统分享面板并附带一张结算图；不支持的浏览器退回到复制链接。
- 没有排行榜和账号，进度只存在本机浏览器里。
