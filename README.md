# YarnTrace · 剥图消消

把一张像素画切成很多「团」，每团有一个带方向箭头的头。点一下，整团沿箭头冲出去：

- **能出去** → 整团飞走，棋盘腾空。
- **被挡住** → 冲出去几格撞停 → 挡它的那一团闪红 → 原路弹回原位（棋盘状态完全不变）。

清空整张画就过关。**没有倒计时，也没有生命值**，什么时候点都行，点错了也不会损失什么。

## 快速开始

```bash
npm install
npm run dev      # 手机同局域网可直接访问，Vite 已开 host
npm run build    # 类型检查 + 产物到 dist/
npm test         # 规则 / 求解 / 生成器 / 会话 / 图片管线
```

产物是纯静态文件（约 27 KB JS + 5 KB CSS），扔到 Vercel、Cloudflare Pages、GitHub Pages 或任意静态主机即可，不需要后端。

## 关卡从哪来

一道关卡 = 像素图 + 切分。图源有四种，最后都归一成 `Art { w, h, palette, color }`：

| 来源 | 说明 |
| --- | --- |
| 程序化生成（默认、无限） | 种子决定画布尺寸、对称轴、生长参数，镜像随机生长出形状，按高度渐变上色 + 外圈描边 |
| 内置模板 | `src/art/templates.ts`：爱心 / 星星 / 苹果 / 蘑菇 / 小鱼 / 猫头 / 云朵 / 小花 |
| 玩家上传 | 选关面板「上传图片」，本地解析，不上传服务器 |
| 随机种子 | 选关面板「随机图案」，URL `?s=<seed>` 可复现同一张图 |

切分用「剥皮法」（`src/game/generator.ts`）：每次只从**此刻就能飞出去**的格子上开一个新团，把它从剩余格子里摘掉，再继续。所以施工顺序本身就是一条合法通关路线 —— 关卡天然 100% 可解，不需要「生成完再校验能不能解」。

> 为什么永远不会卡死：只要还有剩余格子，取其中最靠上的一格，它 ↑ 方向的格子 y 都更小，必然不在剩余集合里，所以它一定能飞。施工永远推得下去。

被挡住、需要先清掉别的团才能动的那些团，就是谜题的来源。

## 目录

```
src/
  game/      types / rng / rules / solver / generator / level registry / session
  art/       程序化图案、模板、图片量化管线、调色板
  render/    相机、贴图缓存、棋盘绘制（静态层 + 活动团）
  ui/        HUD、弹层（选关 / 设置 / 结算）
  store/     localStorage：设置、通关记录
tests/       规则、求解、生成器、会话、图片管线
```

性能要点：棋盘按视野裁剪 + 每种 (颜色, 方向, 头/身) 只栅格化一次贴图，440×440 的像素关（41×40 / 1244 格 / 293 团）生成约 13 ms、求解 5 ms，滚动与动画稳定 60fps。

## 操作

- 点团内任意格 = 点这团
- 双指捏合 / 滚轮 / 底部滑块 = 缩放
- 拖动 = 平移
- 灯泡 = 提示（高亮一个当前能飞出去的团）
- 网格图标 = 辅助线（画出每个团的边界）

## 已知取舍

- 碰撞判定默认只看**头部射线**（`Session` 的 `mode` 可切到 `swept` 做全团扫掠判定）。
- 图案颜色按像素保留，所以同一团可能有多色 —— 图案能和原图 1:1 对上。
- 目前没有音效、PWA、排行榜；分享靠 `?s=<seed>`。
